# 0002: Three scoring frameworks side by side

**Status:** accepted, 0.1.0

## Context

One framework hides its bias. RICE favours reach, ICE ignores it, value and effort ignores confidence.

## Decision

Let the reader switch and see which items move. Items that move a lot have uncertain inputs.

## Tradeoff

- More to explain
- Shows that scores start debates, they do not end them
